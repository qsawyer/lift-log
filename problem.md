# Problem

People who lift at the gym and have trouble tracking their workouts, reps, sets, prs, etc. When using a notebook or the notes app on the phone there is always the chance of losing the notebook or the notes app not getting saved, leaves too much room for data to be lost.

# Initial requirements

- R1: allows input of both rep and set numbers
- R2: sorts by muscle group
- R3: tracks name of exercise
- R4: tracks difficulty to complete (1-10)
- R5: automatically saves after every input
- R6: tracks the weight lifted in lbs
- R7: allows user to view saved data

# Round 2 requirements

- R8: Provides an option for a user to display all of their personal records
- R9: Provides an option for the user to display which exercises they have seen the most improvement in

# Round 3 requirements 

- R10: The user can request a weekly summary of how many workouts they did/ what their prs for the week.

# Round 4 requirements

- R6 (Changed): Used to track the weight lifted in lbs, now gives the user the option to track either in lbs or kg
- R11: User can choose to have weight displayed in both lbs and kg, user can also quickly and easily switch if a number is shown as kg, lbs, or both.

# Round 5 requirements

- R12: Once a unit is set it is saved as the default and doesnt display a question for units, unless the user prompts for it
- R13: Allows the user to delete or edit an entry
